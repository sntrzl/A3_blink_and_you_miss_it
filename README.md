[BLINK AND YOU'LL MISS IT](https://sntrzl.github.io/A3_blink_and_you_miss_it/)  - SHANTAL RAZAL

This work is an interactive sketch built using webcam-based blink detection. It revolves around attention as an involuntary gesture, and the inevitability of things coming to an end. By confronting the user through the simple act of blinking, they try to hold onto the words not realising that every blink accelerates the decay. Small fragmented phrases that try to reach out but also goes. The user cannot see them, only an observer can. In the end what's left is red and the user is left to make sense of what they caught, never given the full picture.

The piece uses a clinical surveillance-like style to emphasise its concept. It explores attention and the impossibility of total presence as both the user, loses the text by existing as a body, and the observer, becomes an unwitting witness to something they cannot share. When all words are gone, the screen cuts to flat red.

Built from handsfree.js sketch "blinking_thisoneworks" by bevbevlauy for real-time facial landmark tracking. TV filter adapted from Glitch_TV code by Karen ann Donnachie and Andy Simionato. Claude.ai was used throughout to assist with code structure, blink detection, and fixing layout and mistakes in the code.
